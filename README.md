# 🌵 Raízes do Nordeste - Lanchonete & Autoatendimento Multicanal

Aplicação Web e protótipo de autoatendimento para a rede de lanchonetes **Raízes do Nordeste**. O projeto explora usabilidade, acessibilidade e princípios de *Privacy by Design* / LGPD em interfaces multicanais (Web, Mobile e Totem de Autoatendimento).

🚀 **Acesse a aplicação online:** https://raizes-do-nordeste-flan-two.vercel.app/

---

## 📌 Funcionalidades Principais

- **Cardápio Dinâmico:** Seleção e filtragem de produtos regionais por unidade da rede.
- **Carrinho & Pedidos:** Gestão de itens, quantidades e cálculo dinâmico de totais.
- **Consentimento & LGPD (Privacy by Design):** Aviso explícito e gestão de privacidade de dados pessoais no primeiro acesso.
- **Simulação de Pagamento:** Fluxo visual integrado para pagamento via Pix e cartão com confirmação de status em tempo real.
- **Programa de Fidelidade:** Acompanhamento e resgate de pontos de recompensa.

---

## 🛠️ Tecnologias Utilizadas

- **React / TypeScript:** Construção da interface dinâmica e tipagem de dados.
- **Vite:** Build tool e ambiente de desenvolvimento ágil.
- **CSS3 / Responsividade:** Design adaptável com abordagem *Mobile-first*.
- **Vercel:** Hospedagem e deploy contínuo via GitHub.
