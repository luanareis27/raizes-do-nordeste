# 🌵 Raízes do Nordeste - Interface Web & Mobile

Interface web moderna, responsiva e performática desenvolvida para a rede  **Raízes do Nordeste**, harmonizando a tradição da culinária regional com uma experiência digital fluida.

🔗 **Deploy na Vercel:** [)


## 📌 Sobre o Projeto

Este projeto foi desenvolvido como **Projeto Multidisciplinar (Trilha Front-End)** para o Curso de Análise e Desenvolvimento de Sistemas do Centro Universitário Internacional UNINTER.

O sistema simula o ecossistema de autoatendimento e pedidos online da rede, contemplando:
- **Conformidade com a LGPD:** Banner e modal explicativo com aceite explícito antes de acessar os serviços.
- **Cardápio Dinâmico:** Filtragem de produtos e preços por unidade física selecionada.
- **Carrinho & Checkout:** Gestão de itens em tempo real e fluxo simplificado de finalização de pedido.
- **Acompanhamento:** Visualização do status em tempo real do pedido enviado à cozinha.
- **Programa de Fidelidade & Perfil:** Gestão de pontos de recompensa e dados do usuário.

---

## 🛠️ Tecnologias Utilizadas

- **React 18** (com TypeScript)
- **Vite** (Build tool e desenvolvimento)
- **Tailwind CSS / CSS Modules** (Estilização responsiva)
- **Lucide React** (Ícones da interface)
